## How it's built

- **Architecture:** service-oriented, with agents as governed services on an enterprise-bus pattern —
  the agent proposes, policy decides, humans approve anything irreversible.
- **AI rails:** Model Context Protocol (MCP) as the distribution rail; capability contracts between
  agents; retrieval-augmented domain knowledge; realtime voice.
- **Safety posture:** agents in regulated domains never diagnose, prescribe, order, or bill — they
  orchestrate. Out-of-band human confirmation for execute-class actions. Client code is treated as
  public by definition; all brains live server-side.
- **Operations:** single-operator fleet discipline — reference implementations over rebuilds,
  surgical deltas over redeployments, backups outside webroots, security audits on a standing cadence.
